# Dwell-confirmed TAEM closure validation

This repository contains the supplementary reproducibility material for the manuscript:

**Dwell-Based Terminal Area Energy Management Closure Validation for Role-Distinct Three-Trajectory Entry Guidance over a Finite Sampled Local Perturbation Set**

## Scope

The repository supports a dwell-confirmed terminal-area energy management (TAEM) closure validation layer for an interaction-free, same-target, role-distinct three-trajectory entry-guidance scenario.

The repository does not claim cooperative multi-vehicle guidance, collision avoidance, wake-aware interaction modeling, exhaustive robustness verification, or runway-aligned precise landing.

## Reported validation campaign

- Case-level strict closure: 49/50
- Vehicle-level strict closure: 149/150
- Validation setting: finite sampled local perturbation support
- Closure logic: dwell-confirmed TAEM event with terminal-reason and close-pass-escape checks

## Repository contents

This repository includes the simulation source files, frozen configuration material, post-processing/replay routines, plotting utilities, representative outputs, and supplementary audit material used to support the manuscript submission.

## Manuscript status

This repository is provided as supplementary reproducibility material for journal submission.
