# Data availability note

Large raw trajectory CSV archives are not stored directly in this Git repository because several combined trajectory files exceed the standard GitHub file-size limits.

This repository contains the source code, configuration files, replay/post-processing routines, plotting utilities, and manuscript-level reproducibility material. Large raw CSV trajectory archives can be supplied separately as supplementary files or through an external archival route if required by the journal.

The reported manuscript-level validation statistics are:
- Case-level strict closure: 49/50
- Vehicle-level strict closure: 149/150
- Final sampled validation setting: finite sampled local perturbation support
